# 上板前确认与台架验收清单（尚未执行）

## 条件

限位独立有效。不得在带载车辆上直接试未批准固件。当前没有实物验证记录，全部步骤待执行。

## 配置门控

`App/bridge_config.c` 默认全零。开启服务前记录并评审以下项目，再同步 CubeMX/协议文档：

| 字段/项目 | 要确认的来源 |
|---|---|
| enabled / approved | 只有所有接线、参数和阈值确认后才同时设 true |
| slave_address | PLC 工程中唯一的 1..247 从站地址 |
| register_base / word_order | PLC 指令的 0 基地址及 uint32 高低字顺序 |
| baud_rate / parity / stop_bits | 与 PLC、CubeMX 一致；本端口支持 8E1/8O1/8N2 |
| de_active_high / de_setup_us | 收发器数据手册、接线、使能建立时间 |
| tx_timeout_ms | 大于最大应答的传输时间+DE 建立+任务调度余量 |
| sbus_timeout_ms | GR01 实测周期、最大抖动、整车安全评审 |
| plc_timeout_ms | PLC 实际轮询、任务周期和允许通信停顿 |
| firmware_version | 记录发布版本与编码规则 |
| DE 与 /RE | 本实现发送时关闭 MCU RX、TC 后立即释放 DE；确认实际收发器支持 |
| GPIO 初始电平 | 当前 CubeMX PB12 初始低；若 DE 为低有效，必须先调整复位/启动默认电平和硬件偏置，不能只改运行配置 |

候选引脚：USART1 PC4/PC5、USART3 PC10/PC11、PB12 DE；它们不是已批准接线表。
USART3 当前 CubeMX 为 115200、8E1，不会由配置函数自动重设。配置与现有外设不一致
时启动失败，不能通过删除检查绕过。GR01 供电 7.2–72 V，不用 NUCLEO 3.3/5 V 供电。

外置收发器须兼容 3.3 V；核对 TX/RX/DE//RE、A/B/GND、电源、隔离/共地及终端。
Q0 COM2 是主站且内置 120 ohm；不要重复并联终端，不把 MCU TX/RX 直连 A/B。

## 分阶段验证

1. 默认禁用版本：心跳持续，g_bridgeStartState/g_bridgeDiagnostics.state 为 DISABLED；
   无输入 has_frame=false、usable=false，USART3 无应答。验证 GPIO 的实际静态电平。
2. SBUS：确认电平/极性/格式后送已知帧，逐通道对比；注入 PE/FE/NE/ORE/DMA
   故障，确认 transport_ok 立即失效、恢复要等新帧。断线检查年龄超时，不依赖 ORE。
3. RS-485：配置批准后接 PC 工具，03 整读/部分读；核对 CRC、字节和字序。
   示波器同时观察 TX、DE、A/B，确认 DE 建立与最后停止位/释放，不用 DMA 完成代替 TC。
4. 时序：测 USART3 单字节 IRQ 延迟、DWT 连续计时、t1.5/t3.5 边界、接收 BUSY、
   高优先级抢占及连续轮询。软件时间戳有 IRQ 抖动，若边界不达标应改硬件计时/捕获，
   不能只放宽规范阈值掩盖。测 SBUS 全链路最坏 IRQ/复制耗时和所有任务栈高水位。
5. 错误：坏 CRC/其他地址/广播不回复；不支持功能和非法范围回异常；过长流、丢字节、
   粘帧、间隔破坏、队列满和 TX 超时后不得发旧应答。停止/重挂失败保留终止诊断。
6. PLC：核对 COM 口/主站角色，单次读完整块；停止轮询出现 COMM_FAULT，恢复请求
   可恢复诊断，但不能自动切换车辆控制权。PLC 自身也必须有通信/序号停滞保护。
7. 安全：遥控器关机、GR01/SBUS/485 断线、各节点复位、无新帧恢复、时钟异常等场景，
   先离线再空载/支轮低速。确认急停不依赖本模块；未通过评审不接入真实执行机构。
8. 延迟：记录原模块与新模块的平均/P95/最大值、抖动，区分帧周期、PLC 轮询、任务和
   传输耗时；尚未测量前不声称满足 30/50 ms 指标或优于原系统。

测试记录至少包含固件/PLC 版本、接线照片、批准配置、原始波形、输入向量、预期/
实际状态、错误计数、恢复过程、最坏耗时、栈余量与未关闭问题。看门狗的启用需另行
批准健康条件；本版本不自动喂狗或控制车辆停车。
